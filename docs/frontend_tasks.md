| 優先度 | タスク | 理由 |

| **高** | 1. プッシュ通知 | アプリのコア機能。ユーザー体験に直結 |

| **中** | 5. 傾向分析 | データ活用でアプリの価値向上 |
| **低** | 4. 目標・報酬 | 3, 5 の基盤が先に必要 |
